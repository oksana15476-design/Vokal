# Чек-лист готовности к запуску

Статус на 2026-09-09. Батч B55.

Список описывает **состояния**, а не задачи: пункт закрыт, когда есть артефакт,
на который можно сослаться. «Работаем над этим» закрытием не считается.

Блокирующее — без этого доступ снаружи не открываем. Желательное — можно
открывать без него, но риск фиксируется письменно и принимается владельцем.

## Легенда

- `—` не начато
- `~` в работе
- `+` закрыто, есть артефакт

## Правило приемки чек-листа

Ни один пункт не помечается закрытым без ссылки на артефакт. Отдельно: пункты
6 и 12 закрываются только фактической проверкой, а не наличием кода и настроек.
Бэкап без проверенного восстановления бэкапом не считается; удаление, не
проверенное прямым запросом по прежнему ключу, удалением не считается.
