# Контекст проекта для кампаний Директа — ШАБЛОН (заполнить под Vokal)

Источник правды для скилла `yandex-direct`. Пока файл не заполнен реальными
данными — **кампании не собираем**: скилл требует читать его перед сборкой.
Не подставлять цифры «по памяти»: нет данных — так и писать «нет данных».

Дата последней сверки кабинетов: _не сверялось_.

## Аккаунты и доступы

- **Метрика:** номер счётчика, домен, регион показа, валюта, часовой пояс.
  Что трекается и что намеренно выведено из трекинга (поддомены, ЛК).
  Токен API — в `.claude/skills/yandex-metrika/config/.env` (в `.gitignore`, не в репо).
- **Директ:** логин (должен совпадать с логином Метрики), баланс/промокод,
  овердрафт-лимит, число кампаний, модель атрибуции.
  Связь Метрика↔Директ появляется после добавления счётчика в настройках кампании.

## Оффер, цена, статус

- Категория, с чем сравниваемся и с чем **не** сравниваемся.
- Цена: указываем в объявлениях или нет (решение владельца), что бесплатно (крючок CTA).
- Статус продукта: что работает сейчас, что «на подключении» — обещать только первое.
- Юр-ограничения тематики (38-ФЗ «О рекламе» + отраслевые): что нельзя утверждать,
  какие дисклеймеры обязательны.
- CTA и рефрен. Юрлицо и бренд в объявлениях.

## Конверсия под оптимизацию

- **Primary:** цель, которая реально стреляет (с числом достижений на срез и файлом
  компонента, который её шлёт). Именно на неё учим стратегии.
- Цели, которые = 0 намеренно, — под оптимизацию **не** брать.
- Если целевых конверсий мало: старт через «Мастер кампаний»/микроконверсии,
  малый бюджет, оптимизация на микроцель.

## Семантическое ядро под контекст

Брать коммерческие кластеры; частотность — broad, нужный регион, Wordstat
(скилл `yandex-wordstat`, лимит 100 req/hour — прогонять ядро один раз).
Группировка — `keyword-clustering`: один кластер = одна группа = один JTBD.

- **Кластер A (приоритет №1):** запросы + частотность.
- **Кластер B:** …
- **НЕ брать в поиск (инфо/обманки):** широкая «голова» тематики и омонимы —
  в контент-воронку/ретаргет, не в поисковую рекламу.
